# DEVELOPMENT RULES

1. The repository remains **PRIVATE** at all times unless the project owner explicitly decides otherwise.
2. All creative content must be original. Architectural lessons may be learned from other games; protected creative content may not be copied.
3. No permanent creative decisions (story, characters, factions, specific locations, dialogue, etc.) without explicit instruction from the project owner.
4. Prefer modular, event-driven design.
5. Document major architectural changes in the relevant docs and in CHANGELOG.md.
6. Follow the rules in UNITY_AI_INSTRUCTIONS.md when using AI assistance.
7. Keep the Unity project reproducible from tracked source files only.
