# OLOMU

Olomu is an original Unity survival, exploration, adventure, and historical-fiction game.

## Development Status

Pre-production / architecture phase.

## Core Principle

> Build the world first. Build the systems that make the world alive. Then let the story emerge through the player's experience.

## Development Tools

- Unity
- Unity AI
- GitHub
- Git

## Repository Purpose

This repository is the authoritative source for Olomu's design, technical architecture, story systems, development rules, and Unity project.

## Repository Status

**PRIVATE.**

Do not publish or make public.

---

## Project Structure

```
Docs/           → High-level design, story, world, systems
GameDesign/     → Core gameplay pillars
Technical/      → Unity architecture & systems design
Development/    → Roadmap, rules, AI instructions, changelog
Research/       → Historical & architectural research notes
UnityProject/   → Actual Unity project (to be added later)
```

## Important Rules

1. All creative content (story, characters, factions, locations, dialogue, etc.) must be original.
2. Architectural lessons may be learned from other games, but no protected creative content may be copied.
3. No permanent creative decisions without explicit approval from the project owner.
4. See `Development/UNITY_AI_INSTRUCTIONS.md` for rules that apply to any AI-assisted development.
