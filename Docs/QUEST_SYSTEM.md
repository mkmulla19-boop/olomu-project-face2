# QUEST SYSTEM

**Status:** High-level design only.

Olomu will use a flexible quest system that can support both authored content and emergent situations generated by the story engine and living-world systems.

## Goals

- Support main story, side stories, character stories, faction stories, investigations, and world events.
- Integrate with the Story Engine (see STORY_ENGINE.md).
- Track player choices and consequences.
- Allow quests to be influenced by world state.

## Implementation Notes

Exact data structures, quest conditions, and runtime behaviour will be designed later.

Do not invent specific quest content yet.
