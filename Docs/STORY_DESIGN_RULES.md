# STORY DESIGN RULES

These principles govern all story and world design work on Olomu.

1. **Olomu must have its own identity.**
2. **The story must be original.**
3. **Historical inspiration must be clearly separated from fictional events.**
4. **The player should discover the world rather than receive every answer immediately.**
5. **Gameplay should contribute to storytelling.**
6. **The world should react to meaningful player actions.**
7. **Characters should have their own motivations.**
8. **Factions should have competing interests.**
9. **Choices should have consequences.**
10. **Not every mystery needs an immediate explanation.**
11. **Not every story needs to be a main quest.**
12. **Environmental storytelling should complement dialogue.**
13. **The world should be capable of generating new stories.**
14. **Avoid unnecessary exposition.**
15. **Never copy another game’s protected creative content.**

---

These rules apply to all documentation and future creative work. No exceptions without explicit project owner approval.
