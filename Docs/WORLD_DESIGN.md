# WORLD DESIGN

**Status:** Framework updated — four region placeholders established. No invented names or content.

---

## World Development Principle

The world must not exist only for the player.

Whenever possible, communities and factions should have their own:

- goals
- resources
- relationships
- conflicts
- leaders
- trade
- fears
- ambitions
- routines
- changes over time

The player enters an existing world rather than becoming the only thing happening in it.
